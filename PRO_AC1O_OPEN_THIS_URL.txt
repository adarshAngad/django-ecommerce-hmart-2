================================================================================
STEP 1 — RENDER DASHBOARD
================================================================================
Open: https://dashboard.render.com
Click the **Web Service** that shows URL **https://pro-ac1o.onrender.com/** (or the service you want to use for that URL).

================================================================================
STEP 2 — CONNECT THIS REPOSITORY (most important)
================================================================================
Settings → **Build & Deploy**

  Repository: **adarshAngad / django-ecommerce-hmart-2**
  Branch: **main**

Click **Save**. Render may start a deploy automatically.

If you do not change this, the site will keep building **old** code from whatever repo was connected before.

================================================================================
STEP 3 — DATABASE (stops Postgres / template crashes)
================================================================================
Environment → **Environment Variables**

  EITHER **delete** `DATABASE_URL` (app uses SQLite; site should load), OR
  set `DATABASE_URL` to the **full Internal Database URL** from your Render Postgres
  (host must contain a dot, e.g. `....postgres.render.com` — not a truncated `...@dpg-...-a` only).

Recommended (avoids DisallowedHost / CSRF on HTTPS):

  ALLOWED_HOSTS = pro-ac1o.onrender.com
  CSRF_TRUSTED_ORIGINS = https://pro-ac1o.onrender.com

Save.

================================================================================
STEP 4 — BUILD + START COMMANDS
================================================================================
Settings → **Build & Deploy** (or **Start**)

  Build Command:
    chmod +x build.sh && ./build.sh

  Start Command:
    gunicorn Annu.wsgi:application --bind 0.0.0.0:$PORT

Save.

================================================================================
STEP 5 — DEPLOY
================================================================================
**Manual Deploy** → **Clear build cache & deploy** (or **Deploy latest commit**).

Wait until status is **Live** (first request after idle can take ~30–60 seconds on free tier).

Open: https://pro-ac1o.onrender.com/
